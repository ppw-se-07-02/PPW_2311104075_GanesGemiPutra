# Unguided Modul 10.7 – Kelola Produk (PHP + MySQL + Bootstrap)

## Fitur
- Menu sidebar: **Kelola Produk**
- CRUD Produk (Create, Read, Update, Delete)
- Data produk **diambil dari database MySQL**
- Pencarian produk berdasarkan **nama_produk / kategori**

## Cara Menjalankan (XAMPP)
1. Start **Apache** dan **MySQL** di XAMPP
2. Buka phpMyAdmin: http://localhost/phpmyadmin
3. Import file **schema.sql** (buat database & tabel + contoh data)
4. Copy folder project ini ke:
   `C:\xampp\htdocs\unguided_kelola_produk`  (Windows)
5. Akses:
   `http://localhost/unguided_kelola_produk/`

## Konfigurasi Database
Edit `config/koneksi.php` jika nama database/username/password berbeda.
